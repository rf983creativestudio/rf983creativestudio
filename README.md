# RF983 Creative Studio

**Creativity. Technology. Impact.**

Official website repository for RF983 Creative Studio, a digital creative studio offering graphic design, website development, music production, photography, video editing and content writing.

## Structure
- Static HTML pages
- Shared CSS design system in `assets/css/style.css`
- Lightweight JavaScript in `assets/js/main.js`

## Preview
Open `index.html` in a browser or use a local static server.

## Launch checklist
- Add the official phoenix logo asset (not yet present in this repository).
- Add approved portfolio work and label concepts clearly.
- Add verified contact details and social links.
- Connect a secure enquiry form provider and update the privacy notice.
- Review legal terms, business requirements and payment arrangements before accepting client work.

No client testimonials, credentials, pricing, payment processing or backend functionality are fabricated in this starter website.
