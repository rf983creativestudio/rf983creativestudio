THE BRIEF

A digital home
for considered spaces.

NORTHLINE is a fictional architecture practice focused on calm, functional spaces that respond to their surroundings. The goal of this concept was to design a digital portfolio that feels as considered as the spaces it presents.

The experience prioritises strong project imagery, clear navigation and a simple path from discovery to enquiry. Rather than overwhelming visitors with effects, the interface uses proportion, typography and whitespace to create confidence.

“Let the work lead. Let the interface make room.”

EXPERIENCE PRINCIPLES

Clarity at every scale.

01 / Focus

Put projects first with large visual moments and concise supporting context.

02 / Flow

Keep navigation predictable and make it easy to move from work to studio information.

03 / Adapt

Recompose the layout for smaller screens without losing hierarchy or atmosphere.

LAYOUT & STRUCTURE

Designed to breathe.

The proposed homepage opens with a concise statement, a featured project and a small navigation system. Supporting sections introduce selected work, the studio approach and a clear contact route.

VISUAL SYSTEM

Quiet tones.
Strong composition.

The visual direction uses mineral neutrals and architectural greens, with a serif display face for character and a clean sans-serif for navigation and detail. Imagery is treated as the main storytelling element.

Typography direction: expressive serif headlines balanced with compact sans-serif navigation, labels and body copy.

Concept study only. NORTHLINE is a fictional architecture studio created to demonstrate RF983 Creative Studio's website design approach. This is not commissioned client work or a live business website.
